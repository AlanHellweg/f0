内置的 Neovim 配置专门用于审查旁边窗格中的智能体所做的改动。

## 默认视图

`nvim .` 会打开三列：左边是**已修改文件**，中间是文件，右边是**文件浏览器**。已修改文件面板会随着智能体写入而更新，当你聚焦编辑器时，智能体编辑过的文件会自动重新加载。

| 按键 | 操作 |
|---|---|
| `Space gm` | 显示或隐藏已修改文件面板 |
| `Space e` | 显示或隐藏文件浏览器 |
| `Space ui` | 恢复三列布局 |

## 并排 diff

| 按键 | 操作 |
|---|---|
| `Space gd` | 未提交的改动 |
| `Space gD` | 整个分支与 `origin/$F0_BASE`（项目的 `base`）的对比 |
| `Space gh` | 当前文件的历史 |
| `Space gq` | 关闭 diff |

在 diff 中，`Tab` 和 `Shift-Tab` 在文件之间切换，`]c` 和 `[c` 在改动之间跳转，在文件列表上按 `Enter` 打开该文件。

## 长行

行永远不会自动换行，diff 的两侧在横向和纵向上都会同步滚动：

| 按键 | 操作 |
|---|---|
| `zl` / `zh` | 向右 / 向左一列 |
| `zL` / `zH` | 向右 / 向左半屏 |
| `$` / `0` | 行尾 / 行首 |

触控板和鼠标的横向滚动也可以使用。

## 放大

在智能体旁边，diff 会变得很窄。按 `Ctrl-a z` 把编辑器窗格放大到整个窗口，再按一次恢复。
